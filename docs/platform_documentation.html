WhatsApp Automation Platform

Comprehensive System Architecture, Technical Specifications & Functional Documentation
Version: 5.0 (Streamlined Decoupled Architecture)  |  Runtime: Node.js v20+ / TypeScript 5.7+ / Fastify 5.2+  |  Ecosystem: Decoupled Monorepo

1. Executive Summary & Core Mission

The WhatsApp Automation Platform is an enterprise-grade, highly modular monorepo solution engineered to provide autonomous WhatsApp marketing, WhatsApp commerce, logistics coordination, and AI-driven conversational customer support for ecommerce and service businesses.

While its primary flagship implementation is configured for Mintara Bites (an artisanal FMCG brand crafting 100% supari-free mouth fresheners and seed blends in Surat, Gujarat), the platform is fundamentally service-agnostic and universal. By abstracting brand identity, offerings, terminology, and workflows into dynamic configuration schemas, the exact same system effortlessly operates for dental clinics, wellness salons, B2B wholesale distributors, or hybrid enterprises.

Key Architectural Principle: The platform operates as a completely decoupled sidecar to the primary business storefront. It maintains strict read-only isolation over external production databases, ensuring zero risk of schema degradation, lock contention, or accidental data modification.

2. Architectural Topology & Monorepo Structure

The repository is structured as a pnpm monorepo consisting of four independently deployable runtimes (apps/) and six reusable core libraries (packages/):

2.1 Applications (apps/)

  • API Server (apps/api): Fastify HTTP and Webhook engine handling Meta WhatsApp webhooks, ecommerce store events, courier logistics updates, admin REST APIs, and the real-time Live Support Desk UI.
  • AI Support Engine (apps/support-engine): Multi-turn conversational orchestrator leveraging Google Gemini AI, managing customer context memory, multimodal audio/photo ingestion, and autonomous escalation.
  • Marketing Engine (apps/marketing-engine): Audience segmentation engine evaluating RFM customer tiers, generating Hinglish marketing copy, and enforcing 14-day anti-fatigue message protections.
  • Background Queue Worker (apps/worker): Asynchronous task processor handling scheduled message queues, day-25 replenishment reminders, CSAT surveys, and lifecycle habit retention prompts.

2.2 Shared Packages (packages/)

  • @whatsapp-platform/config: Centralized Zod schema validation, environment variable resolution (.env.dev, .env.prod), and dynamic Business Profile schemas.
  • @whatsapp-platform/shared: Pino structured logging with automated PII and credential redaction, custom error hierarchies, and process shutdown routines.
  • @whatsapp-platform/database: Dual-database PostgreSQL abstraction featuring automated SQL AST / keyword guards (assertReadOnlySql) and host safety verification (assertLocalDatabaseUrl).
  • @whatsapp-platform/ecommerce-adapter: Decoupled domain contracts, RFM customer segmentation, daily consumption velocity calculators (~12g/day), and 1-click prefilled checkout URL generators.
  • @whatsapp-platform/whatsapp: Meta WhatsApp Cloud API gateway provider managing interactive buttons, list pickers, catalog messages (product, product_list), typing indicators, and media downloads.
  • @whatsapp-platform/ai: Google Gemini integration supporting multi-turn dialogue, image/audio processing, retries with exponential backoff, and the automated Business Synthesizer.

3. Detailed Functional Modules

3.1 WhatsApp Commerce & High-ROI Conversions

  • Native Meta Catalog & Interactive Browsing: Employs Meta's interactive product and product_list messages directly within chat. Customers browse variants, select pack sizes (150g, 300g, 500g), and receive prefilled checkout URLs.
  • Smart Replenishment Engine: Tracks order history and calculates runout timelines based on product weights and consumption rates (~12g/day; a 300g packet lasts ~25 days). Automatically queues day-25 replenishment reminders with a 1-click reorder button (btn_reorder_favorites).
  • Dynamic Abandoned Cart Recovery: Receives cart.abandoned webhooks. For carts idle over 4 hours, it dynamically mints single-use, 24-hour expiring discount codes (e.g., TREAT10-<suffix>) to incentivize recovery.
  • Click-to-WhatsApp (CTWA) Ad Attribution & ROAS: Captures inbound Meta Ad referral parameters (ad_id, headline, source_id). Launches tailored welcome conversations and computes ROAS metrics (GET /api/analytics/roas).
  • Packaging Refill QR Code Ingestion: Customers scanning QR codes printed on physical packaging pouches (sending messages like KHATAM_REFILL_CHAHIYE) trigger immediate reorder flows with active discounts pre-applied.
  • B2B & Corporate Gifting Intake: Automatically classifies high-ticket inquiries for wedding favors, corporate gifting, or wholesale, capturing event dates and quantities, and escalating directly to the brand founder.

3.2 Multimodal AI Customer Support

  • Context-Aware Multi-Turn Memory: Dynamically compiles customer order history, past dialogue turns, and verified website customer testimonials directly into the Gemini prompt context.
  • Multimodal Ingestion: Ingests audio voice notes (interpreting English, Hindi, and Gujarati/Hinglish) and customer photos (for damage claims or order verification).
  • Strict Delivery Redirection Policy: For customer security and carrier accuracy, shipping status inquiries ("where is my order") are intercepted and redirected to the store's official web portal, preventing AI hallucinations.
  • Autonomous Escalation & AI Mute Policy: When a customer requests human help, reports damaged goods, or the AI flags an issue via [ESCALATE: <reason>]:
    1. Conversation state shifts to escalated, instantly muting the AI assistant.
    2. A ticket is logged in support_tickets.
    3. An administrative WhatsApp alert is dispatched containing the full conversation transcript, order history, and a direct wa.me link.
    4. The customer receives a reassuring acknowledgement with a 🤖 Resume AI Bot button.
  • Daily Message Rate Limits: Enforces a configurable per-customer daily quota (default: 25 messages) to prevent automated loops and API cost spikes.

3.3 Post-Purchase Journey & Logistics Coordination

  • Proactive Refrigeration Nudge: On order.delivered webhooks, detects temperature-sensitive items (e.g. Artisanal Paan Mukhwas containing fresh rose gulkand) and immediately alerts the customer to refrigerate it upon arrival.
  • Proactive NDR (Non-Delivery Report) Resolution: Ingests delivery failure events from courier APIs (Shiprocket, Delhivery, Bluedart). Interactively prompts the customer on WhatsApp for updated landmarks, floor numbers, or timing before Return to Origin (RTO) occurs.
  • Automated CSAT / Review Collection: Dispatches a 1-5 star survey 3 days post-delivery:
    • 5 Stars: Records positive review and shares direct Google Review and Instagram profile links.
    • 4 Stars: Logs satisfaction and thanks the customer warmly.
    • 1-3 Stars: Apologizes, logs the feedback, and auto-generates an escalation ticket for customer care follow-up.
  • Hinglish Habit-Building Retention Loop:
    • Day 2: Fridge placement tip (storing beside cold water bottles).
    • Day 4 (9:15 PM): Post-dinner habit trigger ("Plate saaf ho chuki hai na?...").
    • Day 14: Dining table anchor cross-sell (introducing Seeds Fusion for snacking).

3.4 Live Support Desk Command Center

Built directly into the API server (GET /dashboard/support and GET /admin/support), this responsive web interface provides:

  • Real-time live chat view color-coded by message role (Customer, Bot, Agent).
  • One-click live agent composer sending direct WhatsApp replies via Meta API.
  • Ticket escalation management (resolving tickets, muting/unmuting AI bot).
  • Customer 360 dossier: past orders, lifetime spend, abandoned carts, CTWA ad attribution, and NDR delivery logs.
  • Zero Meta OTP friction for human support staff.

3.5 Universal Business Agnostic Engine

The platform is fully decoupled via the business/ directory:

  • business-profile.json: Single source of truth for brand data, business models (ecommerce, service, b2b, hybrid), terminology, offerings, and notification copy.
  • business-knowledge.md: Domain instructions, FAQs, and brand guidelines for the AI assistant.
  • AI Business Synthesizer: POST /api/business/ingest takes raw unstructured text or brochures, analyzes the business model via Gemini, and automatically configures the platform.
  • ChatGPT Action Integration: Exposes standard OpenAPI 3.1.0 specifications via chatgpt-action-openapi.json.

5. Operational Security & Database Isolation

  • Dual Database Guardrails: The platform database holds state; the external ecommerce store is queried strictly read-only. Modification keywords (INSERT, UPDATE, DELETE, DROP, ALTER) in store queries throw an immediate DatabaseSafetyError.
  • Local Reset Protection (scripts/db-guard.ts): Enforces that pnpm db:reset can strictly run only against local Docker instances (localhost / 127.0.0.1) and halts if run in production.
  • Zero Credential Leakage: Pino structured logger redacts authorization headers, cookies, API tokens, passwords, and Meta signatures.
  • Cryptographic Webhook Verification: Validates incoming Meta and Shopify webhook payloads using HMAC-SHA256 signatures against the raw body buffer.

7. Standard Operating Procedures & Commands

# Development
pnpm dev              # Launch Fastify API server in dev mode
pnpm dev:all          # Run all apps (API, Engines, Worker) concurrently

# Environment Switching
pnpm env:dev          # Switch active .env to local development
pnpm env:prod         # Switch active .env to production

# Local Database Operations (Docker Supabase)
pnpm db:start         # Start local Docker PostgreSQL, Auth, Studio
pnpm db:status        # Display local credentials and ports
pnpm db:reset         # Guarded reset and migration execution
pnpm db:stop          # Stop local Docker Supabase

# Verification & Quality Assurance
pnpm test             # Run complete 14-suite integration test suite
pnpm typecheck        # TypeScript compilation verification across all workspaces
pnpm lint             # ESLint code quality checks
pnpm format           # Prettier formatting verification
